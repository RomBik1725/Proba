## ▶️ Как запустить
1. Открыть `Lab5_Variant6.csproj` в **Visual Studio 2022**
2. Нажать **F5**
3. Откроется главное окно со списком персон

### Управление
| Кнопка | Действие |
|--------|----------|
| **Добавить** | Открыть форму создания Школьника / Студента / Преподавателя |
| **Удалить** | Удалить выбранного из списка |
| **Инфо** | Вывести полную информацию о выбранной персоне |
| **Сортировать** | Сортировка по фамилии (полиморфизм через `IComparable`) |
| **Выход** | Закрыть программу |

## 🏗️ Устройство программы

### Иерархия классов
```
Person (abstract)
├── Schoolchild  — добавляет: Grade (класс), School
├── Student      — добавляет: Group, University, Course
└── Teacher      — добавляет: Position, Experience
```

### Полиморфизм
- Метод `GetInfo()` объявлен виртуальным в `Person` и переопределён в каждом дочернем классе
- Список хранит `List<Person>` — при выводе вызывается нужная версия через полиморфизм

---

## 🔑 Ключевые концепции
- **Абстрактный класс**: `Person`
- **Наследование**: 3 уровня иерархии
- **Полиморфизм**: `virtual` / `override` метод `GetInfo()`
- **Список полиморфных объектов**: `List<Person>`
