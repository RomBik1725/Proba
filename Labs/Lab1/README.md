# Лабораторная работа №1 — Вариант 6
## Тема: Класс «Точка в трёхмерном пространстве»

### Что делает программа
Класс `Point3D` с тремя вещественными полями (X, Y, Z):
- конструктор по умолчанию (все координаты = 0)
- конструктор с тремя параметрами
- свойства X, Y, Z с явными `get { return x; }` / `set { x = value; }`
- метод `Input()` — ввод координат с клавиатуры
- метод `Print()` — вывод координат
- метод `DistanceToOrigin()` — расстояние до начала координат

### Как запустить
1. Открыть `Lab1_Variant6.sln` в Visual Studio
2. Нажать **F5** (или **Ctrl+F5** без отладки)
