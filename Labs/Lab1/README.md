## 🏗️ Устройство программы

### Класс `Point3D`
- **Поля** (закрытые): `double x`, `double y`, `double z`
- **Свойства**: `X`, `Y`, `Z` — доступ к закрытым полям
- **Конструкторы**:
  - `Point3D()` — конструктор по умолчанию (x=y=z=0)
  - `Point3D(double x, double y, double z)` — с параметрами
- **Методы**:
  - `Input()` — ввод координат с клавиатуры
  - `DistanceToOrigin()` — расстояние до начала координат по формуле √(x²+y²+z²)
  - `Print()` — вывод координат на экран

### Класс `Program`
- Создаёт 3 объекта `Point3D`
- Демонстрирует ввод с клавиатуры, конструктор с параметрами, работу свойств
