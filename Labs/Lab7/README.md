## ▶️ Как запустить
1. Открыть `Lab7_Variant6.csproj` в **Visual Studio 2022**
2. Нажать **F5**
3. Откроется окно 800×600 с пустым белым поле

### Управление (через меню)
| Пункт меню | Действие |
|------------|----------|
| **Выбор линий** | Открыть диалог: кол-во линий, цвет, тип кривой, диапазон |
| **Построить** | Отрисовать выбранные кривые на панели |
| **Очистить** | Удалить все графики |
| **Инфо** | Показать список активных графиков |
| **Выход** | Закрыть приложение |

## 📐 Доступные кривые (вариант 6)
| Название | Формула |
|---------|--------|
| Прямая | y = x |
| Парабола | y = x² |
| Гипербола | y = 1/x |
| Окружность | x = r·cos(t), y = r·sin(t) |
| Роза | r = a·cos(3t) (полярная) |

## 🏗️ Устройство программы

### `GraphSettings` — модель настроек
- `CurveType` (0–4) — тип кривой
- `LineColor` — цвет линии
- `LineWidth` — толщина
- `XMin/XMax/YMin/YMax` — диапазон отображения

### `SettingsDialog` — диалог настройки
- Выбор кол-ва линий (1–5), цвета, типа кривой, диапазона X/Y
- Возвращает `List<GraphSettings>`

### `MainForm` — главная форма
- Хранит `List<GraphSettings>` и рисует все кривые при событии `Paint`
- Оси координат рисуются через `GDI+` (`Graphics.DrawLine`)

## 🔑 Ключевые концепции
- **GDI+**: рисование через `Graphics` в `Panel.Paint`
- **Меню (`MenuStrip`)**: навигация
- **Модальный диалог**: `SettingsDialog`
- **Параметрические кривые**: алгоритм расчёта 1200 точек
