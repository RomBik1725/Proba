# Лабораторная работа №7 — Графика GDI+. Кривые

**Тип:** WinForms приложение  
**Вариант:** 6

## Описание

Рисование математических кривых (прямая, парабола, гипербола, окружность, роза) средствами GDI+. Диалог настроек.

## Как запустить

1. Открыть `Lab7_Variant6.sln` в **Visual Studio 2022**
2. Нажать **F5**
