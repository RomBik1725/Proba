## 🏗️ Устройство программы

### Класс `Point3D` (базовый)
- Поля `x, y, z` с валидацией через свойства
- Перегруженные операторы: `+`, `-`, `==`, `!=`
- Переопределённый `ToString()` и виртуальный `GetInfo()`

### Класс `ColoredPoint3D` (наследник)
- Наследует `Point3D`
- Добавляет свойства `Color` и `Size`
- Переопределяет `GetInfo()`
- Перегружает оператор `+` для сложения двух цветных точек

### `InfoForm`
- Модальное диалоговое окно (открывается через `ShowDialog()`)
- Показывает информацию об обеих точках и расстояние между ними

---

## 🔑 Ключевые концепции
- **Наследование**: `ColoredPoint3D : Point3D`
- **Перегрузка операторов**: `+`, `-`, `==`, `!=`
- **`virtual` / `override`**: метод `GetInfo()`
- **Модальное окно**: `InfoForm.ShowDialog()`
