# Лабораторная работа №4 — Вариант 6
## Тема: Наследование. Перегрузка операторов.

### Что нового по сравнению с ЛР №2
| Добавлено | Описание |
|-----------|----------|
| `virtual` у свойств и `Print()` | Разрешают переопределение в наследнике |
| Класс `ColoredPoint3D : Point3D` | Наследует `Point3D`, добавляет `Color` (string) и `Size` (int) |
| Переопределение `Print()` | Вызывает `base.Print()`, затем выводит цвет и размер |
| Операторы `+`, `-` | Поэлементное сложение/вычитание координат |
| Операторы `==`, `!=` | Сравнение координат двух точек |
| Полиморфизм | Массив `Point3D[]` хранит объекты `Point3D` и `ColoredPoint3D` |

### Как запустить
1. Открыть `Lab4_Variant6.sln` в Visual Studio
2. Нажать **F5**
