## ▶️ Как запустить
1. Открыть `Lab10_Variant6.csproj` в **Visual Studio 2022**
2. Нажать **F5**
3. Откроется форма
4. Нажать **«Сгенерировать»** — создастся файл `points3d.dat`
5. Задать параметры сферы и нажать **«Проверить точки в сфере»**

### Управление
| Элемент | Назначение |
|---------|----------|
| **Кол-во точек** (5–100) | Сколько точек записать в файл |
| **«Сгенерировать»** | Создать `points3d.dat` со случайными точками (каждая: 3 double) |
| **CX, CY, CZ** | Центр сферы |
| **R** | Радиус сферы |
| **«Проверить точки в сфере»** | Прочитать `points3d.dat` и найти точки внутри сферы |

## 🏗️ Устройство программы

### Формат файла `points3d.dat`
```
[число точек : int32]
[точка 1: x (double), y (double), z (double)]
[точка 2: x (double), y (double), z (double)]
...
```

### Алгоритм поиска точки внутри сферы
```
для каждой точки (x, y, z):
  dist = √( (x-cx)² + (y-cy)² + (z-cz)² )
  если dist <= R  →  точка внутри
```

---

## 🔑 Ключевые концепции
- **`BinaryWriter`**: запись точек в бинарный файл
- **`BinaryReader`**: чтение точек из бинарного файла
- **формула расстояния**: внутри сферы `dist <= R`
