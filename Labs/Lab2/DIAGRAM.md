## Структура класса Point3D (UML)

```
+-------------------------------------------+
|                 Point3D                   |
+-------------------------------------------+
| - x : double = 0.0         (поле, спос.1) |
| - y : double = 0.0                        |
| - z : double = 0.0                        |
| - name : string = "Неизвестно" (спос.1)  |
+-------------------------------------------+
| + Point3D()                               |  ──┐
|     : this(0.0, 0.0, 0.0)                |    │ цепочка
| + Point3D(x, y, z)                        |  ──┤ this
|     : this(x, y, z, "Точка")             |    │
| + Point3D(x, y, z, name="Точка")          |  ──┘ основной
+-------------------------------------------+
| + X : double  { get; set [validate] }     |
| + Y : double  { get; set [validate] }     |
| + Z : double  { get; set [validate] }     |
| + Name : string { get; set ?? "Неизв." } |
| + DistanceToOrigin() : double             |
| + Print() : void                          |
+-------------------------------------------+
```

---

## Цепочка вызовов конструкторов

```
new Point3D()
    │
    └──► Point3D(0.0, 0.0, 0.0)      [: this(0,0,0)]
              │
              └──► Point3D(0, 0, 0, "Точка")  [основной конструктор]
                        │
                        ├─ X = 0  (через сеттер с валидацией)
                        ├─ Y = 0
                        ├─ Z = 0
                        └─ Name = "Точка"
```

---

## Валидация свойств

```
Присвоение значения свойству X/Y/Z:
  │
  ├─ IsFinite(value)?  ──► НЕТ ──► throw ArgumentException
  │
  └─► ДА ──► поле x/y/z = value

Присвоение имени свойству Name:
  │
  └─ value ?? "Неизвестно"  ──► name = результат
```

---

## 4 способа инициализации (Main)

```
[Способ 1] Значение по умолчанию в поле:
  private string name = "Неизвестно";

[Способ 2] Значение по умолчанию в свойстве:
  set { name = value ?? "Неизвестно"; }

[Способ 3] Значение по умолчанию в параметре конструктора:
  Point3D(x, y, z, string name = "Точка")

[Способ 4] Инициализатор объекта:
  new Point3D { X = 1, Y = 2, Z = 2, Name = "Особая точка" }
```
