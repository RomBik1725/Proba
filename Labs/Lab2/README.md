## 🏗️ Устройство программы

### Класс `Point3D` (Point3D.cs)
Расширение класса из Лаб.1. Добавлены:
- **3 конструктора с цепочкой `this`**:
  - `Point3D()` → вызывает `Point3D(0, 0, 0)`
  - `Point3D(x, y, z)` → вызывает `Point3D(x, y, z, "Точка")`
  - `Point3D(x, y, z, name)` — основной конструктор
- **Поле `name`** со значением по умолчанию `"Неизвестно"` прямо в объявлении
- **Свойства с валидацией**:
  - `X`, `Y`, `Z` — проверяют `double.IsFinite()`, отклоняют NaN и Infinity
  - `Name` — при `null` автоматически подставляет `"Неизвестно"`

### Класс `Program` (Program.cs)
Демонстрирует все 4 способа инициализации:
1. Конструктор по умолчанию (поле класса)
2. Конструктор с параметрами
3. Параметр конструктора со значением по умолчанию
4. Инициализатор объекта `new Point3D { X=1, Y=2, Z=2 }`

И два случая валидации:
- Попытка присвоить `NaN` → исключение `ArgumentException`
- Присвоить `null` имени → автозамена на `"Неизвестно"`
