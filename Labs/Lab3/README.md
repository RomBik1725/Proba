## ▶️ Как запустить
1. Открыть `Lab3_Variant6.csproj` в **Visual Studio 2022**
2. Убедиться, что установлен `.NET 8 SDK` с компонентом **Windows Forms**
3. Нажать **F5**
4. Откроется **графическое окно** Windows Forms

### Управление интерфейсом
| Элемент | Действие |
|---------|----------|
| **TrackBar** (скорость) | Изменить скорость анимации |
| **CheckBox** (пауза) | Поставить/снять паузу |
| **RadioButton** (цвет) | Выбрать цвет анимации |
| **Кнопка «Сброс»** | Вернуть начальные настройки |
| **Кнопка «Инфо»** | Показать информацию о программе |
| **Кнопка «Выход»** | Закрыть программу |

## 🏗️ Устройство программы

### Форма `MainForm`
- **Timer** — управляет циклом анимации (тик каждые N мс)
- **Panel** (область рисования) — отображает анимированный объект
- **TrackBar** — ползунок скорости (связан с интервалом таймера)
- **CheckBox** — пауза анимации (включает/отключает таймер)
- **RadioButton** — выбор цвета объекта
- **Метод `panel_Paint`** — перерисовывает объект при каждом тике

---

## 🔑 Ключевые концепции
- **WinForms**: создание графического интерфейса
- **Timer + событие Tick**: цикл анимации
- **Событие Paint**: пользовательская отрисовка на Panel
- **Нестандартные элементы**: TrackBar, CheckBox, RadioButton
