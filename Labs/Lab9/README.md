## ▶️ Как запустить
1. Открыть `Lab9_Variant6.csproj` в **Visual Studio 2022**
2. Нажать **F5**
3. Откроется форма с автоматически загруженными 10 автомобилями

### Управление
| Действие | Описание |
|---------|----------|
| **Добавить** | Ввести марку, модель, год, цвет, пробег — добавить в Dictionary |
| **Удалить выбранный** | Удалить выделенный автомобиль по ключу |
| **Удалить старые** | Удалить авто старше N лет (по году) |
| **По году / По пробегу** | Сортировка через LINQ `OrderBy` |
| **Найти** | Поиск по марке/модели (`Contains`) |
| **LINQ статистика** | Сред. пробег, уник. марок, новейшая модель |
| **Все** | Сбросить фильтр — показать все авто |

## 🏗️ Устройство программы

### Класс `Car`
- Свойства: `Brand`, `Model`, `Year`, `Color`, `Mileage`
- **Ключ**: `GetKey()` — `"{Brand}_{Model}_{Year}"` — уникальный ключ в Dictionary

### `MainForm`
- **`Dictionary<string, Car> cars`** — основная коллекция
- Отображение в `ListBox`; индекс в ListBox ↔ позиция в `cars.Keys.ToList()`

---

## 🔑 Ключевые концепции
- **`Dictionary<string, Car>`**: ключ = строка `Brand_Model_Year`
- **LINQ**: `Where`, `OrderBy`, `Average`, `Select`, `Distinct`, `MaxBy`
- **Лямбда-выражения**: фильтрация и сортировка
